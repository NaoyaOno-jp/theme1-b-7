# イキテル

## 誰の、どんな困りごとか
離れて暮らす 50 代の会社員の娘。母は 80 代で軽い認知症があり、一人暮らし。
課題：母は毎日の電話や確認ボタンを忘れてしまう。そのため、家で倒れていても娘はすぐに気づけない。
## コア機能1つ
高齢者が生活の中で、電気がついた、消えた、をプラグとコンセントの間に挟む中継器の
センサーが、検知する。16 時間どちらもなければ、家族に知らせる。 離れて暮らす家族
に安否確認の通知が届く機能。

## 誰が・いくら・なぜ払うか
誰が：見守る側の家族
いくら：本体０円（貸出）サブスク月額５００円
なぜ：・毎日電話しなくても、親が生きていると分かる。
　　　・親は何も操作しなくてよいので、押し忘れや機器を外されることがない
　　　・ Wi-Fiが要らず、初期費用0円で始められる。競合はSIM内蔵型でも初期費用が8,800〜15,000円かかる
　　　・住んでいる自治体に見守り機器の補助があれば、負担はさらに減る
　　　・誰でも簡単に設置可能
