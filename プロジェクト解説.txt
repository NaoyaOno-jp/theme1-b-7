イキテル ─ プロジェクト解説
==========================

「イキテル」は、照明の点灯・消灯を手がかりに、離れて暮らす親を家族が見守る
アプリの試作品です。デモでは、画面下のボタンで照明と中継器の動きを再現します。

1. ファイル階層

theme1-b-7/
├── index.html
├── style.css
├── app.js
├── README.md
├── プロジェクト解説.txt
└── .git/

画面を開く入口は index.html です。ブラウザーで開くと、同じフォルダーにある
スタイルシートと JavaScript を読み込みます。.git/ は変更履歴を管理するフォルダーです。

2. 各ソースファイルの役割

  index.html  画面の構造を決める。状態カード、時刻、履歴、操作ボタンを配置する。
  style.css   画面の見た目を決める。色、文字の大きさ、余白、部品の並び方を設定する。
  app.js      画面の動きを決める。操作を受け取り、時刻と履歴を管理して表示を更新する。

README.md には、想定する利用者や料金案など、サービスの企画が書かれています。

3. 各ソースファイルのコード解説

3.1 index.html ─ 画面の部品を用意する

  ・<head> で style.css と app.js を読み込みます。<script> に付いている defer は、
    画面の部品が読み込まれてから JavaScript を実行するための指定です。
  ・<header> にアプリ名と見守る相手、<main> に状態カードと時刻、直近の記録を置きます。
    たとえば id="last-change" は、app.js が最後の点灯・消灯時刻を書き込む場所です。
  ・画面下部に「電話する」「無事を確認」「留守にする」と、照明・中継器・時刻を操作する
    デモ用ボタンを置きます。「電話する」のリンクは href="tel:" で、電話番号は空欄です。

3.2 style.css ─ 画面の見た目を決める

  ・:root に状態ごとの色や文字色を CSS 変数として定義します。.app では画面の横幅を
    最大390pxに設定して中央に置き、ヘッダー、メイン画面、操作欄を縦に並べます。
  ・.status-card の data-status という属性に応じて、カードの背景色、文字色、アイコンを
    切り替えます。ok は緑のチェック、check は黄の「！」、off は灰色のプラグです。
  ・記録行の data-event に応じて点の色を切り替えます。下部の操作ボタンは3列、
    デモ用ボタンは2列です。通知までのバーの色は CSS、バーの長さは app.js が設定します。

3.3 app.js ─ 操作を受け取り、状態と表示を更新する

  ・初期データと時計
    state に最後の点灯・消灯時刻、中継器の最終信号時刻、家族が確認した時刻、
    留守設定、履歴を持たせます。初期画面では約1時間12分前の消灯を表示します。
    now() は現在時刻に早送りした時間を足したデモ時刻を返します。再読み込みすると
    記録や留守設定、デモ時刻は初期状態に戻ります。

  ・ボタン操作と中継器の信号
    照明ボタンを押すと、接続中の中継器を想定して receiveLightEvent() が点灯・消灯と
    その時刻を記録します。接続中は simulateHeartbeat() が10分間隔の稼働信号を再現し、
    「中継器を抜く」では信号を止めて時計を30分進めます。「中継器を差す」と信号が
    すぐに復帰します。「無事を確認」は確認時刻を履歴に追加し、16時間を数え直します。

  ・状態の判定と通知
    computeStatus() は最後の信号から30分以上経つと off（機器の電源切れ）を返します。
    信号が途絶えていない場合は、baseTime() が選んだ時刻からの経過時間で判定します。
    起点は最後の点灯・消灯時刻と家族の確認時刻のうち新しい方です。16時間以上なら
    check（確認が必要）、16時間未満なら ok（通常）です。
    handleStatus() は信号が途絶えた記録の重複を防ぎ、check になったときの通知を
    起点ごとに1回処理します。sendNotification() は結果を開発者ツールのコンソールに
    出力します。留守中も経過時間の判定や照明の記録は続き、通知は見送ります。

  ・画面の更新
    render() が状態に応じて表示文、data-status、通知までの時間とバーを更新します。
    renderRecords() は履歴のうち新しい5件までを画面に並べます。render() は起動時と
    操作時に加え、画面を開いている間は1分ごとに実行されます。

  処理の流れは「16時間経過」ボタンで確認できます。中継器が接続された状態で押すと、
  app.js が時計を進めて check と判定します。index.html の状態カードに
  「確認してください」と表示され、style.css の指定でカードが黄色になります。
